\subsection{回归测试方法（改代码后必做）}
\begin{enumerate}
  \item \textbf{编译}：\code{cd src \&\& make}，确认 \code{EXIT=0}；
  \item \textbf{参数等价性}：对至少一个算例跑短程，用
\begin{lstlisting}
diff <(grep -v "namelist groups found" old/output_para.out) \
     <(grep -v "namelist groups found" new/output_para.out)
\end{lstlisting}
        比对生效参数；结构改动（如分组）应“除新增回显行外逐行一致”；
  \item \textbf{数值/稳定性}：\code{grep -i nan run.log} 应为 0；残差应下降；\code{EXIT=0}；
  \item \textbf{重启往返}：跑一段（写出 \code{field\_restart.dat}）后重启续算，
        确认 \code{Kstep/tt} 正确恢复、无 NaN、界面量零跳变；
  \item \textbf{节点输出}：\code{python3 util/check\_flow3d\_node.py} 核对块维度/点数与 \code{Mesh3d.x} 一致；
  \item \textbf{接口诊断}：新拓扑先用 \code{IF\_Debug=1} 检查 \code{L1..L3} 与 \code{face/face1}。
\end{enumerate}

\noindent 读法：$\varepsilon=0$ 的 $u,v,w$ 逐点为浮点 0（通过）；$\varepsilon=1$ 的阻力自零
（有 O(10) m/s 流动，通过），但其速度方向与参照不同（未通过）；三个多孔算例的 $T$ 都停在
初值、$T_s$ 最多 +3 K（能量未推进）。

\paragraph{已确认}
\begin{itemize}
  \item 五例全部 \code{EXIT=0}、\code{run.log} 无 \code{NaN}，
        \code{util/check\_flow3d\_node.py} 报 \code{STRUCTURE OK}；
  \item $\varepsilon=0$ 时块1 的 $u,v,w$ 在\textbf{全部节点}（含鬼点层写入的边界节点行）
        逐点为浮点 0 —— “不可渗固体极限”的显式冻结分支按设计工作；
  \item $\varepsilon=1$ 时 Darcy/Forchheimer 源项确实消失（块内出现 O(10) m/s 流动，
        而 $\varepsilon=10^{-6}$ 时 $|u|\lesssim10^{-9}$ m/s），未出现发散。
\end{itemize}

\paragraph{尚未通过（负结果）}
\begin{itemize}
  \item \textbf{$\varepsilon=1$ 与低速块的逐点一致性不成立}：块1 主速度分量在
        $u$（$\pm17.6$ m/s），参照 \code{run\_ref\_case2} 在 $v$（17.7 m/s）；
        \code{--blocks 1} 对照给出 $\max|\Delta u|=17.6$ m/s、$\max|\Delta v|=28.0$ m/s、
        $\max|\Delta T|=96.3$ K，差值\textbf{不限于}界面相邻排。原因之一是界面码 19
        的气体侧是“无滑移等温壁 + 可选发汗”，而码 12 是流--流连续；多孔侧的界面处理
        也可能不允许冷却剂穿出，使块内形成回流而非贯穿流。
  \item \textbf{$\varepsilon=0$ 与固体块的温度场不重合}：$\max|\Delta T|=498.6$ K
        （\code{run\_por\_eps0} 的 $T_s$ 只到 303 K，固体参照到 800 K）。两 deck 仅
        接口码 19 vs 11 不同，因此这一步检验的其实是\textbf{界面壁模型}，不是块内导热。
  \item \textbf{多孔块能量几乎不推进}：三个多孔算例的流体 $T$ 均停在初值 300 K，
        $T_s$ 最多变化 3 K —— \code{Niter\_Couple\_Outer=2}、\code{Porous\_Chunk\_Iter=2}
        时多孔段一共只被调用 4 次，来不及响应。
\end{itemize}

\noindent 因此表 \ref{tab:limitresults} 的定位是\textbf{回归快照}（分支不崩 + $\varepsilon=0$
速度精确为零），不是“$\varepsilon=1$ 复现低速、$\varepsilon=0$ 复现固体”的定量证据。
要取得定量证据需：① 对照双方使用\textbf{同一接口模型}（12$\leftrightarrow$12 或
19$\leftrightarrow$19）；② 把外层轮数与多孔段预算提高一个量级（或跑到稳态）。

\subsection{已知问题与待办（摘要）}
\begin{itemize}
  \item \textbf{多孔速度入口}存在约 28\% 通量缺口（“流量锁定”未实现为按面法向的通量约束）；
  \item \textbf{$\varepsilon$ 极限的定量对照未通过}（界面码 19 的壁模型 + 压缩调度 +
        $\varepsilon=1$ 多孔侧可能不允许穿出），见第 \ref{sec:limitresults} 节；
  \item \textbf{低速压力求解器}为迭代型（Jacobi/GS），建议换 BiCGStab/ILU 以加速并提高鲁棒性；
  \item \textbf{低速网格病态}：\code{flatplate\_re1e6}、\code{high\_low\_fluid} 收敛慢/精度受损；
  \item \textbf{耦合外迭代}可加 Aitken/Anderson 加速；
  \item \textbf{接口 17（固--多孔）/18（多孔--多孔）未实现}；码 12/19 无跨进程耦合；
  \item \textbf{合并 VTK} 改分区输出以降低内存/IO 峰值；
  \item 三例 \code{cases/fluid\_solid/*/README.md} 待补充；
  \item \code{util/readflow3d-ver2.4a/2.5.f90} 仍存在“同一 \code{control.ec} 连两个 unit”的隐患
        （旧编译器会报错，修法与主程序一致）。
\end{itemize}
