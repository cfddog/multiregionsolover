\section{固体导热求解器（\code{BLOCK\_SOLID}）}
\label{sec:solid}

\subsection{模型与离散}
块类型 1，\textbf{稳态导热}（\code{src/sub\_multi\_region.f90: solid\_solver\_one\_block}）。
有限体积法，逐格心热平衡
\begin{equation}
k\sum_{faces}\frac{A_{f}}{d_{f}}\,(T_{nb}-T_{i}) = 0 ,
\end{equation}
其中 $d_f$ 取\textbf{相邻格心连线的欧氏距离在面法向的投影}（含非正交修正，$\cos\phi$ 截断到 $\ge 0.1$），
因此支持非均匀网格与非直角曲线网格（O 网格等）。固体温度存于 \code{B\%Ts}（K，SI），
初值为 \code{T\_inf}（可压参考温度）。

\paragraph{日志（2026-09-26 起统一格式）}固体 GS 每 100 次扫掠打 1 行过程监视行，
求解结束再打 1 行汇总行（\code{final=}），两者格式一致：
\begin{lstlisting}
 Region res [solid GS |dTs|] block   1 (BLOCK_SOLID) step=   1400 : max= 0.34994764E-06  rms= 0.19965370E-06  at (i,j,k)=(    1   74    1)  xyz=[ 0.332071E+00 -0.899771E-02  0.250000E-01] m
\end{lstlisting}
三个量依次是：\code{max} $=\max\lvert\Delta T_s\rvert$（即 \code{Solid\_Tol} 的判据量）、
\code{rms} $=\sqrt{\sum \Delta T_s^2/N}$（区域内平均水平）、\code{at (i,j,k)} $=$ 最大变化所在胞
及其胞心物理坐标 $[$\code{m}$]$。扫掠数达到 \code{Solid\_Max\_Iter}$+1$ 说明\textbf{未达容差}
（需增大上限、调 $\omega$ 或检查边界）。此前的 \code{GS iter} / \code{DBG: Ts(...)} 逐次调试输出已删除。

\subsection{并行推进：跨进程扫掠数统一（\code{Solid\_Sync\_Chunk}）}
\label{sec:solid_parallel}
固体 GS 的收敛判据 $\max\lvert\Delta T_s\rvert<$\code{Solid\_Tol} 原本是\emph{每个块、每个进程各自}
判断的。可是每一次扫掠都会调用 \code{update\_Ts\_buffer\_onemesh}（\code{Ts\_send}/\code{Ts\_recv}
成对点对点交换），于是 \textbf{两个进程必须执行完全相同的扫掠次数}；否则一方已在
\code{MPI\_Recv} 等待对方永远不会再发的消息，表现为“固体求解卡死不返回”
（各进程拥有的块数/网格量/材料参数不同时，局部扫掠数必然不同）。

2026-10-18 起（P3）改为\textbf{分块同步推进}（\code{solid\_solve\_all\_blocks}）：
\begin{enumerate}
  \item 先在本地所有 \code{BLOCK\_SOLID} 上各推进 \code{Solid\_Sync\_Chunk} 次扫掠；
  \item 用一次 \code{MPI\_Allreduce(MPI\_MAX)} 把本地 $\max\lvert\Delta T_s\rvert$ 归约成\textbf{全局值}；
  \item 停止判据改用全局值：
        $\big(\text{res}_{glob}<\texttt{Solid\_Tol}\ \wedge\ \text{sweeps}\ge\texttt{Solid\_Min\_Iter}\big)$
        或 $\text{sweeps}\ge\texttt{Solid\_Max\_Iter}$；
  \item 由此每个进程的判据、退出时机与界面交换次数\textbf{完全相同}，不会失配。
\end{enumerate}
没有固体块的进程同样进入循环（内层空转）并参与 \code{MPI\_Allreduce}，集合通信次数也一致。
代价是 $N/$\code{Solid\_Sync\_Chunk} 次 \code{MPI\_Allreduce}（默认 20000/100 $=$ 200 次，
每次仅 1 个 \code{double}，开销可忽略）；\code{Solid\_Max\_Iter} 最多被超出
\code{Solid\_Sync\_Chunk}$-1$ 次扫掠（各进程一致）。

\begin{itemize}
  \item np$=$1 或 \code{Solid\_Sync\_Chunk}$\le0$：走\emph{原来的}逐块路径，
        \code{solid\_solver\_one\_block} 的行为与旧版\textbf{逐字节相同}；
  \item np$>$1：\code{solver\_one\_block} 内的 \code{BLOCK\_SOLID} 分支只登记、
        \emph{不}就地求解，改由块循环之后的 \code{solid\_solve\_all\_blocks} 统一推进
        （分段交错码 11/13 的固体分段同理）；
  \item 并行收敛信息另打一行（rank 0）：
\begin{lstlisting}
 solid sync (parallel): sweeps=    1400  global max|dTs|= 0.91234567E-09  converged= T  (identical on every MPI rank)
\end{lstlisting}
        逐块的 \code{Region res [solid GS |dTs|]} 行语义不变（仍是该块/该进程的值）。
\end{itemize}

\subsection{热边界（\code{solid\_bc.inp}）}
逐面给定：\textbf{$T_w>0$ 等温壁（K）；$T_w<0$ 给定热流 $Q_w$ [W/m$^2$]}；可选追加
\code{htc}/\code{Tinf} 列（对流边界）。未列出的面默认绝热（零梯度）。

\subsection{与流体/低速的共轭耦合（码 11 / 13）}
耦合例程在每个交界面按\textbf{热流平衡}计算界面温度（\code{compute\_interface\_T}）：
\begin{equation}
T_i=\frac{k_f\,T_f/dx_f + k_s\,T_s/dx_s}{k_f/dx_f + k_s/dx_s},
\qquad
\text{鬼点：}\ T_{ghost}=2T_i-T_{interior},
\end{equation}
其中 $dx$ 为格心到界面的距离，$k_f$ 已换算到流体无量纲体系
（$k_{ref}=\mu_{ref}c_{p,ref}/Pr_L$，$\mu_{ref}=\rho_{ref}Ma\,a_{ref}\texttt{Lscale}/Re$），
$k_s$ 为固体 SI 值（\code{material.in} 第 3 列）。方向/指标映射由连接描述符 \code{L1..L3} 完成，
支持任意 $(face,face1)$ 组合（$6\times6$）。

\paragraph{两种 CHT 模式（\code{Iflag\_Couple\_WallFlux}）}
\begin{itemize}
  \item \code{0}（默认，耦合式）：界面 $T_w$ 与 $q_w$ 由两侧场即时热流平衡得到；
  \item \code{1}（等温 $T_w$ / 热流 $q_w$ 壁通量式，\code{wfmode}）：气体侧把界面当\textbf{等温壁} $T_w$，
        固体侧施加热流 $q_w$，适合分段交错里"先算气体 $q_w$、再算固体"的流程（\code{cases/fluid\_solid}）。
\end{itemize}

\subsection{成本与使用建议}
\begin{itemize}
  \item \textbf{单次调用成本}：默认 $20000/10^{-9}$ 时，case1 规模（$67\times101\times2$）实测约
        \textbf{1400 次扫掠/次}；在\textbf{每时间步}都求解固体的强耦合模式下约 15--20 s/步
        （因此切强耦合时会自动把预算降到 \code{Solid\_Max\_Iter}$\le20$、\code{Solid\_Tol}$\ge10^{-6}$，
        见 \S\ref{sec:restart}）。
  \item \textbf{分段交错模式}下固体每外层轮只解一次，成本可接受，是长时程 CHT 的推荐用法。
  \item \textbf{稳定性}：界面热流很小时可适当放宽 \code{Solid\_Tol}（如 $10^{-7}$）以省时间；
        固体内部温差大/网格畸变严重时降低 $\omega$。
  \item \textbf{验证算例}：\code{solid\_1d}（一维线性解析，误差 $\sim10^{-6}$ K）、
        \code{solid\_annulus}（环形径向导热对数解，径向误差 $\sim1.9\times10^{-3}$ K）、
        \code{bl\_cht}（低速--固体共轭，码 13）。
\end{itemize}
