\paragraph{维护规则}程序每新增或修改功能，必须：
\begin{enumerate}
  \item 更新正文对应章节（含参数表）；
  \item 新增参数时同步附录 A；
  \item \textbf{在下表追加一条记录}（日期 / 版本 / 功能 / 涉及源码 / 验证算例与结果）；
  \item 重新编译本手册（\code{cd docs/程序说明 \&\& ./build.sh}）确认无错误。
\end{enumerate}
