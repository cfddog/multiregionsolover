> 本仓库为多块、多区域混合求解框架：在可压缩密度基基线（OpenCFD-EC 1.16a）之上，扩展了
> 不可压低速、固体导热、多孔介质（LTNE）及多区域显式接口耦合能力。
> 本文按“能力 → 考核算例 → 验证状态”组织，可作为功能自检与算例清单参考。

> 型耦合（`couple_compressible_porous_blowing_face`）与“分段交错”外层迭代
> （`run_staggered_fluid_porous`，气体段→提 q_w→多孔段→回 T_w），新增

## 2. 能力清单

### 2.1 可压缩密度基求解器（基线继承，原 OpenCFD-EC 1.16a）

- 多块有限体积 N-S，粘性/无粘；LU-SGS、双时间步、多网格、MPI/OpenMP。
- 空间格式：UD1 / NND2 / UD3 / MUSCL(2U/2C/3) / OMUSCL2 / WENO5 / UD5 / WENO7 等。
- 无粘通量：Steger–Warming / HLL / HLLC / Roe / Van Leer / AUSM。
- 湍流模型：BL / SA / New-SA / SST（k–ω）；壁距自动计算。
- 其它：多重网格、周期性边界、涡轮机内流模式、混合 FV/FD（SEC 嵌入区，`FDM.in` 控制，
  WENO5/WENO7/OMP6），初场/重启（`flow3d.dat`），气动力/力矩输出。

### 2.2 低速不可压求解器（`src/sub_lowspeed.f90`）

- SIMPLE / SIMPLEC 压力–速度耦合，Rhie–Chow 插值抑制棋盘压力。
- 对流格式：一阶迎风 / SOU / MUSCL（`LS_Scheme`）。
- 入口三类：速度入口（1）、质量流量入口（2）、压力入口（3）——由 `LS_Inlet_Type` 切换；
  物理边界类型码 21（低速入口）/ 22（低速出口）；压力出口零梯度外推 + 静压给定。
- 顶盖驱动等壁面滑移型边界由 `LS_U_lid` 支持。
- 物性/求解参数组：`LS_rho, LS_mu, LS_k, LS_Cp, LS_T_ref, LS_P_in/out, LS_alpha_*, LS_Max_Iter, LS_Tol`。
- **AC 虚拟压缩求解器（`LS_Algorithm=3`，`src/sub_lowspeed_ac.f90`）控制量**（2026-09-08 起，2026-09-17 扩充）：
  `AC_Max_Iter / AC_Print / AC_beta / AC_CFL / AC_CFLv / AC_Tol / AC_w`；
  `AC_Flux`（1=Rusanov(LLF) 默认，2=Steger–Warming 特征分裂；**3=AUSM+ 已于 2026-09-17 移除**，
  见 §6-14）；`AC_Recon`（1=二阶 MUSCL(van Leer) 默认，2=WENO5，3=WENO3）；
  `AC_Limiter`（1=van Leer，2=minmod）；`AC_WenoBlend`（0..1，WENO 路径混入的一阶 Rusanov 比例）；
  `AC_WallRecon`（1=默认，壁/对称面切向状态用单侧二阶重构）；`AC_WallP`（1=默认，壁面压力二阶线性重构）；
  `AC_MomDiss`（0=默认 lumped；1=逐场分裂混合式、2=纯 `|u_n|` 不稳定）与 `AC_MomFrac`（默认 0.2）；
  越界值由 `ac_check_controls()` 打印告警并回落到安全默认（不再静默使用未定义值）。
- 支持不可压能量方程（温度）与共轭传热（见 2.3/2.4）。
- 低速块变量约定（2026-09-07 统一）：`U(1)=ρ`（定值 `LS_rho`）、`U(2..4)=速度分量`（**存速度而非动量**）、
  `U(5)=T`、压力存 `B%p`；初场冷启动（`src/sub_init.f90`）与全部接口例程已按此约定修正
  （旧代码 `ρu` 仅在 ρ=1 kg/m³ 时恰好正确）。

### 2.3 固体导热求解器（`src/sub_multi_region.f90` 内 solid 分支）

- 有限体积、3D，支持非均匀网格与非直角曲线网格（O 网格等）。
- 输入 `Mesh3d.dat` / `Mesh3d.x`（`Mesh_File_Format` 切换），VTK/后处理输出。
- 热边界：`solid_bc.inp` 按“面号 Tw(K) Qw(W/m²)”给定（Tw<0 表示给热流）。
- 类型 1 块参与流体–固体、低速–固体共轭耦合。

### 2.4 多孔介质求解器（`src/sub_porous.f90`）

- 不可压 + Ergun 渗透率 `K = d_p²ε³/[150(1−ε)²]`、Darcy–Brinkman–Forchheimer 阻力源项
  （并入 SIMPLE 动量方程，与压力梯度按同一体积积分方式处理）。
- **LTNE 局部非热平衡双温度模型**：`U(5)=Tf`（流体温度）与 `B%Ts`（骨架温度）通过 `hv`
  （体积换热系数）耦合，骨架方程含 `(1−ε)k_s` 导热。
- 参数文件：`porous.inp`（块号 eps dp hv）、`material.in`（块类型 3 + 骨架 ρ/Cp/k）、
  `solid_bc.inp`（骨架壁面热边界）；`Porous_Max_Iter / Porous_Tol / Porous_alpha_Ts`。

### 2.5 多区域耦合框架（`src/sub_multi_region.f90`、`src/sub_update_buffer_mpi.f90`）

- 显式接口码（11–19）驱动：读入 `bc3d_interface.inp` 后自动配对、接口面顺序自动对齐。
- 逐块求解 + 外层块迭代：各块各自 SIMPLE 内迭代后交换接口 ghost
  （如 `couple_lowspeed_porous_interfaces`，见 `cases/beavers_joseph/README.md` 代码改动摘要）。
- 物理边界与接口（`bc≥11`）分流处理，接口不重复施加物理 BC。
- **可压–低速接口（码 12，`couple_highlow_fluid_face`，2026-09-07 修正）**：
  - 低速→可压 ghost 无量纲化所依赖的参考密度改为实时反推 `ρ∞=Re·μ_SI(T∞)/(Ma·a∞·Lscale)`
    （Sutherland 定律算 μ_SI，原固定 1 kg/m³ 只对特定参考态成立），低速侧速度去掉 ρ 因子；
  - 仅当低速块**无压力 Dirichlet 物理面**（速度入口 + 壁面 + 交换面）时才整场平移锚定 p；
    压力入口（`LS_Inlet_Type=3`）或压力出口存在时跳过平移，避免入口 ghost 保持 `LS_P_in`
    而内部被清零造成的虚假压力梯度。
- **低速–多孔接口（码 16，`couple_lowspeed_porous_interfaces`，2026-09-07 扩展）**：
  i/j/k 三个方向正负共 **6 种面配对**均可交换，按 LAP 层 ghost 直接拷贝 `U(1..5)` 与 `B%p`；
  已在主程序三处外层块迭代位置统一调用（`src/opencfd_ec3d_v1.16a.f90`）。
- **可压–多孔接口（码 19，`BLOCK_FLUID ↔ BLOCK_POROUS`，2026-09-08 Phase B）**：
  - 分派：当流体块邻接多孔块时，`LS_Inlet_Type==1`（多孔侧为冷却剂**速度入口**）走
    **吹气/发汗型** `couple_compressible_porous_blowing_face`（多孔热端=冷却剂出口，
    零梯度 + 壁压 p_w(SI) 闭锁多孔 SIMPLE 压力问题；可压热端面=壁面+法向质量注入，
    G=LS_ρ·LS_U_in，T_w=Tf(多孔热端胞)，v_w=G/ρ_w，切向镜像），否则退回 Phase A
    剪切型 `couple_highlow_fluid_face`（G=0 参考）；
  - 另有 **分段交错外层迭代** `run_staggered_fluid_porous`（`Iflag_Couple_Scheme=1` 时主程序
    改走该路径）：高速流段（可压推进 Kstep_Couple_Comp 步、code-19 面按等温壁 T_w 施加）
    → 提取界面热流 q_w(x)（Sutherland+Pr）与壁压 p_w(x) → 多孔段（推进
    Porous_Chunk_Iter 次 SIMPLE/LTNE，流体出口 ghost p=p_w、骨架 Ts 热流外推
    `Ts_g=Ts_i+q_w·dx/k_s_eff`）→ 返回界面温度 `T_w=(Ts_i+Ts_g)/2`，直至
    `max|ΔT_w|<Tol_Couple_Tw`；
  - 新增控制量：`Iflag_Couple_Scheme / Kstep_Couple_Comp / Niter_Couple_Outer /
    Porous_Chunk_Iter / Niter_Couple_Warm / Kstep_Couple_Min / Twall_Couple_Init /
    Tol_Couple_Tw`（`src/sub_modules.f90`、`src/sub_read_parameter.f90`，参与 MPI 广播）；
    支持“暖机大步长→减半精修”两阶段用法（见 `staggered_tw/README.md`）。

### 2.6 后处理输出：合并 VTK 与 SI 单位换算（2026-09-07 新增）

- `Iflag_vtk_onefile`（默认 0）：=1 时不再逐块写 `flow3d_block_*.vtk`，所有**流场**块合并写入单个
  非结构 VTK `flow3d.vtk`（`UNSTRUCTURED_GRID` 六面体，cell data：density/velocity/temperature/
  pressure），便于一次加载多块/多区场（固体、多孔骨架温度仍写 `Ts_block_*.vtk`）。
- `Iflag_vtk_SI`（默认 0，可压块按无量纲输出）：=1 时在写 VTK 前把可压密度基块换算为 SI 物理量，
  换算比例按来流参考态 + Sutherland 实时求得：`U∞=Ma·a∞`、`ρ∞=Re·μ_SI(T∞)/(Ma·a∞·Lscale)`、
  `T∞`、`p∞=ρ∞U∞²`；低速/多孔块本身以 SI 存储，不再缩放——低速–可压混接算例由此可在
  同一文件/同一量纲下直接比较两区场。
- 两个开关经参数文件读取并参与 MPI 广播（`src/sub_read_parameter.f90`、`src/sub_modules.f90`）；
  逐块与合并两种写入路径均支持 SI 换算（`src/sub_IO.f90: output_vtk / output_vtk_merged_flow`）。

### 2.7 输入标准化：`control.ec` 7 组 namelist（2026-09-23 新增）

- 原单一 `$control_ec` 组含 **128 个变量**，全部都有代码默认值；实测算例文件中 70~75% 的赋值行
  与默认值相同。现按物理/功能域拆为 **7 组**：

  | 组 | 变量数 | 内容 |
  |---|---|---|
  | `$freestream_ec` | 24 | 来流条件 / 参考态 / 气体物性（`Ma,Re,AoA,AoS,p_outlet,gamma,PrL,PrT,T_inf,Twall,Lscale,Ref_S,Ref_L,Centroid,Cood_Y_UP,Kt_inf,Wt_inf,Turbo_*` …） |
  | `$flow_ec` | 49 | 时间步/迭代、格式、湍流模型、网格与并行、限制器、输出开关（`t_end,Kstep_save,CFL,Iflag_Scheme,Iflag_Flux,Mesh_File_Format,Num_Mesh,Iflag_vtk_*` …） |
  | `$lowspeed_ec` | 21 | 低速不可压块全部 `LS_*` |
  | `$ac_ec` | 15 | 人工压缩求解器 `AC_*`（低速与多孔共用） |
  | `$solid_ec` | 4 | 固体导热 GS 控制 `Solid_GS_Omega/Solid_Max_Iter/Solid_Min_Iter/Solid_Tol`（原为代码内硬编码，默认值与原值全等） |
  | `$porous_ec` | 8 | 多孔块全部 `Porous_*` |
  | `$couple_ec` | 11 | 跨区域（分段交错）耦合调度 `Iflag_Couple_*` 等 |

- **兼容性**：旧组 `$control_ec`（含 128 变量 + `Solid_*`）**完全保留**，`cases/**/control.ec`
  **无需改动**；新旧并存时分组值优先（可逐组渐进迁移）。
- **读取规则**：先扫描文件判定实际出现的组（`!` 后为注释；只有首个非空字符为 `$`/`&` 的行
  才算组头）→ 读旧组 → 按 `freestream→flow→lowspeed→ac→solid→porous→couple` 顺序读实际存在的组。
  **每组、每个变量都可省略**（用默认值）；**组存在但解析失败**（拼错变量名/缺 `$end`）会
  报错并 `stop 1`，不静默回落默认值。启动时 `output_para.out` 末尾回显各组来源，便于回归比对。
- 模板与详细说明：`control.ec.template`、`docs/control.ec-说明.md`。
- 后处理工具 `util/readflow3d-ver2.4a/2.5.f90` 同步支持新格式，并修复了原先缺失
  `Lscale`/`LS_*`/`AC_*`/`Porous_*`/`couple` 变量导致**读现代算例必失败**的历史遗留问题。
- 验证：`cases/solid_1d`、`cases/channel_ac` 新旧二进制 `output_para.out` 除新增 4 行回显外
  **逐字节一致**；新格式取值、分组覆盖旧组、严格报错、模板 7 组同时存在均通过。

### 2.8 重启文件与节点流场输出（2026-09-23 新增）

- **重启文件 `field_restart.dat`**（`src/sub_restart.f90`，开关 `$flow_ec: Iflag_restart/Kstep_restart`）：
  写入**流场 `U`（含 LAP=4 层鬼点缓冲区）**、固体/多孔骨架温度 `Ts`/`Tsn`、低速/多孔压力 `p`，
  以及**计算步数 `Kstep` 与时间 `tt`**（头记录还含 `Ma,Re,gamma,T_inf,Lscale,dt_global` 便于校验）。
  默认与 `Kstep_save` 同节奏定期写出；启动时**若文件存在则自动续算**（`Iflag_restart=0`），
  不一致则回退到原初始化（均匀场 / `Iflag_init`），`Iflag_restart=1` 时不可用即 `stop 1`。
  读入后自动刷新块间缓冲，因此高精度格式的缓冲信息被精确恢复。交错耦合模式（`Iflag_Couple_Scheme=1`）
  的三个驱动入口已改为“有重启则恢复 `Kstep/tt`”，并在每轮气体段保存点与运行结束处写出重启文件。
- **节点流场输出 `flow3d_node.dat`**（`src/sub_IO.f90::output_flow_node`，开关 `$flow_ec: Iflag_flow_node`）：
  把格心量按 **8 格心平均**插值到**网格节点**，单位换成 **SI**（可压块按 `U∞/ρ∞/T∞` 参考态换算，
  低速/多孔块本身存 SI），**unformatted、逐块一条记录、`d,u,v,w,T`、块序与 `Mesh3d.x` 一致**，
  固体块按 `flow3d.vtk` 约定 `d=u=v=w=0, T=Ts[K]`。因此可直接与 `Mesh3d.x` 组合显示流场。
- 验证（详见 `docs/重启与节点流场输出说明.md`）：单块续算往返（`Kstep=11 → 20`，无 NaN）；
  节点文件维度与 `Mesh3d.x` 完全一致（4131 / 13534 / 40602 点）；**多进程 2 块**（`-np 2`）
  写出并成功续算，SI 数值物理合理（Ma=3：ρ≈0.10–0.13 kg/m³、u≈788–1701 m/s、T≈800–1174 K）；
  交错耦合 case1 在 `Kstep=50/100/150` 均写出两文件且无 NaN。

   下即病态发散（cap=30 外迭代 ~7 步发散），现用等效（涡）粘性 `LS_mu=2.38e-4`（ν=1e-2 m²/s，
   Re_eff≈O(10²)）保证数值收敛；按真实 Re 的严格物理模拟需先加密/重建该块网格并重新标定
   低速块松弛参数。
10. **合并 VTK 目前仅含流场块、且为单进程汇总**：`Iflag_vtk_onefile=1` 时 `flow3d.vtk` 只覆盖
   流场块（固体/多孔骨架温度仍各自写 `Ts_block_*.vtk`），由 0 号进程汇总、ASCII 非结构格式；
   大规模输出建议后续补并行写与二进制/XDMF。
11. **可压–低速接口仅“量级自检”**：Ma=3 试跑中超声速区仍在发展（max 残差 O(1e-3)，非定常），
   尚未给出界面两侧的定量剖面对比（如与平板边界层 / 剪切层解析解核对换算因子 ρ∞、U∞ 的一致）。
12. **接口 19 Phase B 分段交错耦合的限制（2026-09-08，见 `staggered_tw/README.md`）**：
   (a) 必须有粘性（`If_viscous=1`）才有物理热流；121×81 均匀通道网格对 Ma3 / Re≈5.6e6/m
   层流边界层远不够（首层 dy≈0.6 mm，需 ~1e-5 m 加密），外循环因温度剖面未稳而暂不收敛；
   (b) 若需“前段绝热平板 + 后段发汗”需把可压 j- 底壁拆成 code-2/code-19 子面；
   (c) 多孔热端热流目前全部进入骨架 Ts（经 hv 换热），流体相热端为零梯度+压力出口——
   表面孔隙直接分流/加热冷却剂需按表面孔隙率扩展；
   (d) 外循环需对 T_w/q_w 欠松弛或“暖机大步长→减半精修”；单块对、共形、仅支持
   可压 j- ↔ 多孔 j+，且现阶段按单进程使用；
   (e) `Init_flow` 重启路径只恢复可压区，多孔 p/Ts 被重置——跨进程续算多孔骨架温场尚未支持
   （同一运行内可用“暖机+减间隔”两阶段参数）。
13. **可压块 SI 换算按理想气体 + Sutherland 反推参考态**（`output_vtk`/`output_vtk_merged_flow`）：
   ρ∞=Re·μ_SI(T∞)/(Ma·a∞·Lscale)，仅对单一来流参考态严格成立；同一算例不同块来流态不同时
   需按块给参考量（后续工作项）。
14. **`AC_Flux=3`（AUSM+）已移除（2026-09-17）**：AC 方程无物理声速，AUSM+ 的马赫分裂与
   LU-SGS 使用的 `c=sqrt(un²+β)` 口径不一致，且实现的版本缺少低马赫压力耗散项
   （AUSM+-up 的 p_u），在无粘圆柱上 2000 步内 NaN（`cases/cylinder_re40_half/inv_ausm/run_ausm.log`）。
   现仅支持 `AC_Flux=1`(Rusanov) / `2`(Steger–Warming)；其它取值由 `ac_check_controls()`
   告警并回落为 1，历史算例 `control.ec` 里的 `AC_Flux=3` 仍可加载（按 1 运行）。

# 编译（src/）

## 9. 下一步优化提升建议

> 依据 §6 已知问题、各算例 README 与 `docs/程序帮助开发笔记.md` 整理，按“收敛/物理一致性 →
> 功能扩展 → 效率与可用性 → 质量保障”排列优先级。括号内为直接受益的算例/文件。

### 9.1 先解决收敛与物理一致性问题（P0）

1. **多孔速度入口“流量锁定”（§6-1）**：强阻力下单孔块速度入口存在 ~28% 通量缺口。
   建议（a）把入口压力修正的边界条件从“速度给死”改为“面通量 + 压力修正零梯度”的约束，
   或（b）采用 README 已规划的“纯流体–多孔–纯流体”三块结构，把速度入口放在流体块上、
   多孔块只走接口 ghost。先以 `cases/porous_plug/velinlet` 收敛到柱均 u/u_in≈1 为验收标准。
2. **低速块网格病态（§6-9）**：high_low_fluid / flatplate 的退化网格迫使使用等效粘性，
   掩盖真实 Re。建议先用双曲正切/椭圆光顺重建 Block1 与 flatplate 网格（网格因子、最大折转角、
   最小体积三者同时达标），再按真实分子粘性重跑，并重新标定 `LS_alpha_*`/`LS_Max_Iter`；
   同时在求解器内加入非正交 + skew 修正项（SIMPLE 类通用做法），降低对网格质量的敏感度。
3. **flatplate_re1e6 读入 EOF / Blasius 复核（§5-🟡）**：统一 `Mesh3d.dat/.x` 与 `flow3d.dat`
   两套网格读入逻辑、补齐 EOF 保护与格式探测；以 Blasius 剖面/摩阻完成定量记录后，
   该算例可同时作为低速块“壁面加密 + 压力入口”的回归基准。
4. **run_lid Re=1000 重跑（§6-8）**：≥80×80 加密网格 + SIMPLEC/MUSCL 收敛到内迭代容差后，
   用 `run_lid/compare_profiles.py` 出正式图与偏差表；可顺带验证压力–速度耦合对网格的收敛阶。

### 9.2 补齐耦合能力与物理模型（P1）

5. **接口 17 / 18（SolidPorous / PorousPorous）+ 接口 19 Phase C（§6-2 / §6-12）**：
   17/18 仍按开发笔记 Zhang/Betchen 界面公式实现（复用 `couple_*` 面配对/ghost 框架）；
   19 的 Phase A/B 已落地，下一步完成 **Phase C 框架热平衡闭合**（code 注释预留）与
   `staggered_tw` 的定量收敛：加密网格 + `If_viscous=1` + 每段足够推进步数后，核对
   `q_w、T_w、p_w` 沿流向分布与发汗冷却效率（对已知解析/经验关联），并补“绝热前段 +
   发汗后段”分段底壁、多孔 Ts 重启读回与多进程支持。
6. **LTNE 定量验证 + 输出完整（§6-3/§6-4）**：与 Wakao 体积换热关联或二维 LTNE 解析解对比，
   校验 `hv` 标定；把 `B%Ts` 写入 `flow3d.dat` 重启文件（现仅 dat/vtk 输出），使多孔算例可续算。
7. **可压–低速接口定量化（§6-11）**：选一个两侧都有解析解的稳态构型（如亚声速-不可压分区平板 /
   剪切层）长时推进到定常，对比界面两侧 u/T/p 剖面，正式确认 `ρ∞、U∞` 换算与压力锚定逻辑。
8. **低速湍流能力**：为不可压块接入 SA/SST（或 `k–ω` 低雷诺数版 + 壁面函数），打通
   “低速–多孔”“低速–固体”在中高 Re 工程构型上的应用；多孔块可先只做层流/阻力主导验证。

### 9.3 数值效率与易用性（P2）

9. **SIMPLE 压力求解与收敛加速**：压力 Poisson 用 BiCGStab/ILU 或代数多重网格替代当前逐点
   迭代；`LS_alpha_*` 自适应标定（残差振荡时自动回落），减少手调参数。
10. **区域耦合外迭代加速**：可压–低速、流体–多孔显式逐块顺序耦合在密度比/速度比大时收敛慢，
    建议外层块迭代加 Aitken/Anderson 或界面隐式处理，并统计每外步各块 SIMPLE 内迭代次数以定位瓶颈。
11. **大规模/并行输出**：合并 `flow3d.vtk` 现由 0 号进程汇总（§6-10），建议改各进程写
    `flow3d_block_*` 分区文件 + `.visit`/XDMF 时间序列；可选二进制 VTK。
12. **单文件 VTK 增加块标识与温度场**：给 `flow3d.vtk` 每个 cell 附 block id（并可选并入
    `Ts_block_*.vtk`），方便按块着色筛选。

### 9.4 工程化与质量保障（P3）

13. **消除 6 面 ghost 代码重复**：`couple_*` 中逐面拷贝逻辑大量重复，建议抽公共
    `fill_ghost_faces(Bs, Bn, field…)`，减少新增接口（17/18/19）的移植错误面。
14. **统一回归测试入口**：把 `check_ghia.py`、`validate_analytic.py`、`plot_validation/pv_*.py`
    汇总成一个可一键运行的 `run_regression.sh`（含基准残差阈值），配合 git 提交做冒烟回归。
15. **文档与注释中文乱码清理**：源码注释中仍有编码错乱（如控制参数注释），建议统一 UTF-8，
    并把 `control.ec` 各 `Iflag_*`/`LS_*` 的语义补成与 §2.6 一致的可检索注释。
