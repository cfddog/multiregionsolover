# lidcavity_ac — 顶盖驱动方腔(AC-FV,LS_Algorithm=3)Re=100 / Re=1000 考核

在 `feat/lowspeed-ac-fv` 分支虚拟压缩求解器上的方腔验证。
单元方形腔,H=1,顶盖 j+ 面以 `LS_U_lid=1 m/s` 运动,其余三壁静止;ρ=1 kg/m³,
`LS_mu=1/Re`(`If_viscous=1`,需启用粘性项;注意 SIMPLE 时代 `If_viscous` 不影响 LS)。

| 子目录 | Re | 网格 | μ (LS_mu) | AC 收敛 |
|---|---|---|---|---|
| `re100` | 100 | 41×41×2 节点(40×40 单元,均匀) | 0.01 | 15 524 次伪迭代,res<1e-7 |
| `re1000` | 1000 | 81×81×2(80×80 均匀) | 0.001 | ≈8 万次内收敛 |
| `re1000_str` | 1000 | 81×81×2(轻度拉伸,首层 0.0107) | 0.001 | 52 594 次伪迭代 |
| `re1000_tanh` | 1000 | 81×81×2(双曲正切加密,首层 0.0034) | 0.001 | 74 445 次伪迭代 |

参数:`LS_Algorithm=3`、`AC_beta=1`(β=U_ref²,U_ref=LS_U_lid)、`AC_CFL=20`、
`AC_Max_Iter=80000`、`AC_Tol=1e-7`;无压力 Dirichlet 边界 → 程序自动做压力均值锚定。

## 与 Ghia et al.(1982)对比(`analyze_cavity.py`)

竖中心线 x=0.5 的 u(y):

**Re=100**(40×40 均匀网格)
- u-RMS≈**0.021**,u_min=−0.213(Ghia −0.211);
- 近顶盖 u(y=0.977)=0.845(Ghia 0.841);u(y=0.5)=−0.208(Ghia −0.206)。

**Re=1000**(80×80)
- 均匀:`u-RMS≈0.044`,u_min≈−0.36(Ghia≈−0.38);
- 轻度拉伸(首层 0.0107):`u-RMS≈0.035`,u_min≈−0.364;
- 双曲正切加密(首层 0.0034):`u-RMS≈0.034`,u_min≈−0.350;
- 上/中部(y≥0.45)三种网格偏差均<0.02;底部 y≈0.06–0.10(sim −0.14/−0.23 vs
  Ghia −0.20/−0.30)对壁面加密不敏感——残差主要来自强剪切角区/低涡区的数值耗散与
  总点数,需更高阶重构或 160² 加密验证,而非单纯首层间距。

> 说明:u 剖面数据排布/对照与仓库既有 `check_ghia.py` 一致;v(y=0.5)参考表在不同
> 脚本间含义不一致,暂不列为判据(可后续统一到流函数/准确 v 表)。

## 运行与复现

```bash
cd re100   # 或 re1000 / re1000_str / re1000_tanh
mpirun -np 1 ../../../../src/opencfd-ec1.16a.out
cd ..
python3 analyze_cavity.py re100 re1000 re1000_str re1000_tanh
# re1000_tanh: 网格由本目录 gen_mesh.py --nx 81 --ny 81 --stretch_y --beta_y 3.2 生成
```

## 结论与待办
- AC-LU-SGS 在方腔(全壁面、无压力 BC)稳定收敛,压力均值锚定正常;Re=100 精度与
  仓库内 SIMPLE@40×40 相当,Re=1000 主涡量级/位置正确;
- 提高 Re=1000 精度:换用壁面加密(双曲正切/几何)80×80 网格(`run_lid/mesh_str_80`)
  或更高阶重构;之后输出正式定量记录并纳入 docs 考核总结。
