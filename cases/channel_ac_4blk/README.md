# channel_ac_4blk —— 2×2 四块分解槽道（多块 AC **角点**构型验收）

与 `cases/channel_ac_2blk` 完全相同的物理与总分辨率（Lx=8、H=1、ρ=1、μ=0.02、
入口 u=1、出口 p=0、无滑移壁、80×40 单元/块 × 4 块 = 全网格 160×40），但域在
**x 与 y 两个方向同时切分**：

```
 y
0.5 +---- blk3 ----+---- blk4 ----+
    |              |              |
 0  +---- blk1 ----+---- blk2 ----+
    0              4              8    x
```

于是 **4 个共形 `BC_Inner(-1)` 界面在内部点 (4, 0.5) 交汇**（并沿两条内部线相交）——
即 T 形管交汇区的类比，用来判定**多块 AC 是否存在角点病态**。各块 41×21×2 节点
（40×20 单元），`gen_case.py` 生成 `Mesh3d.x` / `bc3d.inp` / `bc3d_interface.inp` /
`material.in`（4 块均为 `BLOCK_LOWSPEED`）：

- blk1：i- 入口(5) | i+ 界面→blk2 | j- 壁(2) | j+ 界面→blk3 | k± 对称(3)
- blk2：i- 界面→blk1 | i+ 出口(6) | j- 壁(2) | j+ 界面→blk4 | k± 对称(3)
- blk3：i- 入口(5) | i+ 界面→blk4 | j- 界面→blk1 | j+ 壁(2) | k± 对称(3)
- blk4：i- 界面→blk3 | i+ 出口(6) | j- 界面→blk2 | j+ 壁(2) | k± 对称(3)

> **文件说明**：四块**同为 `BLOCK_LOWSPEED`**，属同类块 ⇒ 对接关系与物理边界全部写在
> `bc3d.inp`（内边界负码），由 `sub_convert_inp.f90::Convert_bc` 自动求出
> `ib1..ke1`/`nb1`/`face1`/`L1..L3` 写入 `bc3d.inc`。**本目录不含 `bc3d_interface.inp`**
> （该文件仅用于**跨类型** block 的对接）。

## 运行（**同步调度**：小内迭代 + 多外步）

```bash
python3 gen_case.py
# 同步调度（正确）：AC_Max_Iter=20, t_end=3000, Kstep_save=1000
../../src/opencfd-ec1.16a.out     # 启动打印 "AC: shared same-class interfaces = 4"
```

> 冻结界面的三组结果里，邻块首列（`i=1`，紧贴界面）都被锁进假解：blk4 出现
> `u_min=−14.4`、`u_max=2.11`，blk2 出现 `u_min=−0.48`（残差却是 1e-7）。同步调度下
> **全部消失**——见 2blk README 的机理说明。

同步调度收敛解（`Kstep_save=1000` 写出的最终 `flow3d_block_*.vtk`）：

| 量 | blk1 | blk2 | blk3 | blk4 | 参考 |
|---|---|---|---|---|---|
| `u_max` | 1.49503 | 1.49561 | **1.49503** | **1.49561** | 解析 1.5；单块 AC 1.49546 |
| `u_min` | 0.07176 | 0.07199 | 0.07176 | 0.07199 | >0，**0 个负速度** ✓ |
| 负速度单元数 | 0 | 0 | 0 | 0 | — |

**结论：未发现角点病态，且解精度达到单块水平。** 4 个界面在内部点 (4,0.5) 交汇的
构型：①四块残差全部到 **1e-14**（比 2 块还低）；②上/下两半**镜像严格对称**
（blk1≡blk3、blk2≡blk4 的 `u_max`/`u_min` 逐位相同）—— 若角点处理有缺陷，这种对称性
会被破坏；③`u_max` 与解析值 1.5、单块 AC 值 1.49546 一致。
