# channel_ac_2blk —— 2 块共形界面槽道（多块 AC 耦合隔离算例）

把 `cases/channel_ac` 的 2D Poiseuille 槽道（Lx=8、H=1、ρ=1、μ=0.02、入口 u=1、
出口 p=0、上下无滑移壁、Re_H=50）在 **x=4 切成 2 块**，中间只有 **一个无旋转的共形
`BC_Inner(-1)` 界面**，用于隔离“多块/界面”对 AC 收敛的影响（与单块同分辨率：每块
81×41×2 节点 = 80×40 单元）。

网格与 BC 由 `gen_case.py` 生成（`Mesh3d.x` / `bc3d.inp` / `bc3d_interface.inp` /
`material.in`，`material.in` 两块均为 `BLOCK_LOWSPEED`）：

- blk1：i- 速度入口(5) | i+ 界面(-1) → blk2 i=1 | j± 无滑移壁(2) | k± 对称(3)
- blk2：i- 界面(-1) → blk1 i=81 | i+ 压力出口(6) | j± 壁(2) | k± 对称(3)

> **文件说明**：两块**同为 `BLOCK_LOWSPEED`**，属同类块 ⇒ 对接关系与物理边界全部写在
> `bc3d.inp`（内边界用负码，连接号/正负维标记在 `kb/ke` 列），由
> `sub_convert_inp.f90::Convert_bc` 自动求出 `ib1..ke1`/`nb1`/`face1`/`L1..L3` 写入
> `bc3d.inc`。**本目录不含 `bc3d_interface.inp`**（该文件仅用于**跨类型** block 的对接，
> 如低速↔多孔/固体）；实测删掉该文件后本算例仍打印 `shared same-class interfaces = 1`
> 并正常收敛。

## 运行（**多块 AC 必须用"小内迭代 + 多外步"同步调度**）

```bash
python3 gen_case.py
# 同步调度（正确）：AC_Max_Iter=20, t_end=3000, Kstep_save=1000
../../src/opencfd-ec1.16a.out
```

**关键**：多块 AC 的每个外步里各块只推进少量内迭代（`AC_Max_Iter=20`），
界面通量/ghost 每外步刷新一次（块间"同步"）。若把某个块一次迭代到收敛
（`AC_Max_Iter=60000, t_end=1`），该块求解期间**界面通量被冻结**，邻块首列会被
锁进一个**假解**（见下表），残差虽到 1e-7 但解是错的。

## 结果（2026-09-15）

| 调度 | blk1 | blk2 | blk2 首列（i=1） |
|---|---|---|---|

| 两侧各自算通量 + 冻结界面（修复前） | 60000 步 6.4e-2 ✗（先降后涨） | 18947 步 9.5e-8 | 同上 ✗ |
