# 不可压缩槽道流动验证（三种入口条件）

验证不可压求解器（SIMPLE + Rhie-Chow + MUSCL）对典型进出口边界条件的处理。

## 算例设置

- 几何：2D 槽道，流向 `x∈[0,8]`，槽高 `y∈[0,1]`（H=1），准 2D（z 1 层）
- 无量纲：`Re_H = ρ Ū H / μ = 50`（ρ=1, μ=0.02, Ū=1）
- 网格：161×41×2 节点（160×40×1 单元），均匀
- 边界（`bc3d.inp`）：
  - x=0（面 1）：入口 `BC_Inflow`
  - x=8（面 4）：出口 `BC_Outflow` 压力出口（速度零梯度外推，静压 `LS_P_out=0`）
  - y=0/1（面 2/5）：无滑移壁面
  - z 面（面 3/6）：Symmetry

生成网格：

```bash
python3 ../lidcavity/gen_mesh.py --nx 161 --ny 41 --nz 2 --Lx 8.0 --Ly 1.0 --dz 1.0
```

三种入口由 `LS_Inlet_Type` 切换（各目录一份 `control.ec`）：

| 目录 | 入口类型 | 关键参数 |
|---|---|---|
| `type1_vel` | 1 速度入口 | `LS_U_in=1.0`（均匀） |
| `type2_mfr` | 2 质量入口 | `LS_Mdot_in=1.0`（=ρŪA，换算后等价于均匀 u=1） |
| `type3_pre` | 3 压力入口 | `LS_P_in=2.0`，速度外推（ΔP 驱动） |

求解控制：`LS_Scheme=3`（MUSCL）、`LS_Algorithm=1`（SIMPLE）、`LS_alpha_u=0.5`、`LS_alpha_p=0.2`、`LS_Tol=1e-8`。

运行（binary 为 `src/` 编译所得 `opencfd-ec1.16a.out`）：

```bash
mpirun -np 1 ./opencfd-ec1.16a.out
```

## 验证结果（x≥5 充分发展区 vs 解析 Poiseuille `u=6Ū y(1-y)`）

解析量：`Ū = ΔP H²/(12μL)`（压力驱动）、`dp/dx = -12μŪ/H²`。

| 入口 | 收敛(步 / res_p) | Ū | 中心 u_max (解析) | 剖面 RMS 误差 | dp/dx 模拟 vs 解析 |
|---|---|---|---|---|---|
| 速度入口 | 1311 / 9.7e-9 | 0.9952 | 1.491 (1.5) | 0.58% | -0.241 vs -0.239 |
| 质量入口 | 1311 / 9.7e-9 | 0.9952 | 1.491 (1.5) | 0.58% | 同速度入口 |
| 压力入口 | 1336 / 9.9e-9 | 1.0416 | 1.560 (1.563) | 0.15%* | -0.251 vs -0.250 |

*按实际 Ū 归一；压力入口 Ū=1.0416 与解析 ΔP 驱动值 1.0417 误差 0.01%。

## 相关代码修复

本算例暴露并修复了 `src/sub_lowspeed.f90` 两个缺陷：

1. 压力修正场 `pp` 在 i-/j-/k- 侧缺边界 ghost（越界读随机值）→ 新增 `lowspeed_pp_ghost`：默认 Neumann，压力固定面（`BC_Outflow`、压力入口）置 `pp=0`。
2. 入口面质量通量符号：`Fi/Fj/Fk` 为坐标正向通量，入口面应加 `+uin*A`；原 i-/j-/k- 侧取负号导致入流变抽吸、收敛出反向流。
