# high_low_fluid_800K — Step-1（解耦两步：热侧热负荷提取）

在 `cases/high_low_fluid` 网格上把**可压区来流温度改为 800 K**（Ma=3，Re/m=5.584e6，
按 800 K 重算参考量：μ∞≈3.62e-5 Pa·s、ρ∞≈0.119 kg/m³、p∞≈27.3 kPa；低速侧 300 K
空气按 p∞ 换算 ρ=0.317 kg/m³，仍用等效粘性 ν=1e-2 m²/s 保证该病态网格收敛）。
Block1（低速块）本步**暂作被冷却壁面替身**（不改为多孔），仍走可压-低速接口码 12。

目的：为"高速高温流体向多孔壁供热"提取等效热流/换热系数。t_end=150 收敛（无 NaN），
从可压 Block3 近界面第一/二行（y≈0，Δy≈1 µm）按 SI 化 T 场 + 局部 Sutherland 导热
计算法向热流：

- 界面（y=0+）气体温度 ≈ **797 K**（沿 x 几乎不变）；
- 进入壁面的热流 **q_w ≈ −2.14e6 W/m²**（≈2.1×10⁶，几乎与 x 无关）。

等效标定（供 Step-2）：取恢复温度 T_rec≈2240 K（Ma=3、T∞=800 K 的滞止温度），
`hg = q_w/(T_rec−T_w) ≈ 1.48e3 W/(m²·K)`。

局限：Block1 是流体替身而非多孔 LTNE 壁，界面温度由该替身决定（≈797 K）；真共轭
（可压↔多孔 码 19）未实现时，此值仅为热侧负荷量级标定。复现：
`mpirun -np 1 ./opencfd-ec1.16a.out`（control.ec：T_inf=800，Iflag_vtk_onefile=0）。
